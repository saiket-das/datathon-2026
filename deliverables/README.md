# Deliverables

Final, team-approved PDFs go here: `dashboards.pdf` and `slides.pdf`. Check them for raw records before committing; only aggregated charts and tables are allowed.

## Submission checklist

Deadline: Thu 19 Nov 2026, 12:00 PM Malaysia time. Team target: uploaded by 10:00 AM.

**Dashboards PDF**
- [ ] 5–15 dashboards, one per feature group
- [ ] Each dashboard states its reconstructed rule(s) clearly
- [ ] At least one chart per feature group showing the rule in the data, against a baseline or comparison group
- [ ] Every chart has a title stating the takeaway, labelled axes, no truncated axes
- [ ] Understandable without the slides
- [ ] Uploaded to Google Drive; link sharing set as the submission form requires

**Slides PDF**
- [ ] 10–20 slides in total, including introduction and methodology
- [ ] At most one summary slide per feature group
- [ ] Each insight restates its rule, shows or references its chart, and gives a real-world economic explanation labelled as interpretation
- [ ] Methodology slides describe how each rule was found (2–3 slides)
- [ ] One slide for the data issues log ([../findings/issues_log.md](../findings/issues_log.md))
- [ ] At least one rejected hypothesis and the behaviours we could not explain
- [ ] Headline finding stated up front; clear conclusion at the end

**Compliance**
- [ ] Only the Swift dataset used as primary data
- [ ] External references cited in APA style with URLs
- [ ] All tools, libraries and pre-existing code disclosed
- [ ] No raw records or redistributable extracts in either PDF
- [ ] Every headline number re-run by a second team member from the scripts in `analysis/`
- [ ] No video needed for the preliminary round
