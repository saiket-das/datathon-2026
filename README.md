# UMDAC Datathon 2026 · Team Workspace

Private collaboration workspace for the UMDAC Datathon 2026 preliminary round (Swift artificial cross-border payments case).

**Competition materials:** See `docs/official-pdfs/` for the five source PDFs and `docs/markdown/` for two page-referenced Markdown compilations. **Start with [`DATATHON.md`](DATATHON.md)** for the short factual brief, and see [`AGENTS.md`](AGENTS.md) for neutral instructions for AI coding agents.

**Submission deadline:** 19 November 2026, 12:00 PM Malaysia time (UTC+8). The organisers' rules require dashboards and a presentation deck in PDF format, submitted through the official submission link.

**Data:** The sponsor's large dataset is intentionally not included. Only obtain it through authorised competition channels, keep it outside Git, and do not upload its contents or redistributable extracts. The `deliverables/` directory is a placeholder for approved final submission materials; no slides or dashboards have been created yet.

**Collaboration:** Use branches/PRs for nontrivial changes and explain how to reproduce evidence behind any conclusions. The team can choose its own division of work, methods, and tooling.
