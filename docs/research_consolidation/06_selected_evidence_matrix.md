## Interpretation rules

- Only the explicitly noted denominator is supported; where original progress summaries omit an exact n, review the linked source before quoting a result elsewhere.
- Confidence or range notations in the table are copied as reported by original investigators; no fresh uncertainty calculation was performed here. A bank-based interval may still be optimistic with shared network structure.
- **Failed frozen rules** A03/A21/A24/B01/B07/B11/C05 remain failures even when one descriptive component looks strong. Of those failures, the table lists selected examples; the full failure register preserves all seven.
- Reporting zero observed errors does not establish a zero population error rate, generalization beyond observed support, independent confirmation, or the original generator source code.
- No numerical private F03 or G01 result, D/E protected source, or unverified local C work is reproduced here.

**Source:** original A/B/C branch progress ledgers and linked hypothesis records. Private results and unsupported subgroups are deliberately excluded.
